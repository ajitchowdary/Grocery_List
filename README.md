# Grocery_List 🛒✨

A ultra-premium Flutter Grocery List application featuring a luxury visual aesthetic, modern glassmorphic designs, rich color palettes, and seamless navigation across Splash, Onboarding, and Home screens.

## Features
- 🌟 **Animated Splash Screen**: Pulsing branding with glowing gradient background.
- 🚀 **Interactive Onboarding**: 3-step feature highlight with custom slide indicators and vibrant visuals.
- 🛍️ **Premium Home Screen**:
  - Live address switcher & notification badge.
  - Search bar with filter menu.
  - Promotional glassmorphic banner.
  - Interactive categories horizontal list.
  - Product grid with discount badges, ratings, and quantity counter controls.
  - Floating bottom cart summary bar.

## Getting Started
To run this Flutter app:
```bash
cd Grocery_List
flutter pub get
flutter run
```
